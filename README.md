# Card Tracker

Card Tracker is a local-first web app for managing a Pokemon card collection and exploring themed binder layouts.

## Development

```bash
npm install
npm run dev
```

The collection is stored in the browser's local storage. No account or remote service is required for the initial experience.

## Supported card fields

- Card name (required)
- Set
- Type
- Rarity
- Quantity
- Notes

Useful checks:

```bash
npm test
npm run typecheck
npm run build
```
